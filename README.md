# Frederik Lysholm Jønsson

AI and Data Engineering student at the Technical University of Denmark, currently on exchange at UC Santa Cruz. I build practical machine learning systems and small AI tools, with an interest in making models useful beyond a notebook.

## Selected work

- **[Worth the Watch?](https://github.com/Trexz14/worth-the-watch)** — A Chrome extension that uses video captions and an LLM to show the main point of a YouTube video before you open it.
- **[Text Quality Classification](https://github.com/Trexz14/ml-ops-assignment)** — A DTU group project that fine-tunes a compact BERT model to classify text readability. The repository covers training, evaluation, API serving, containerisation, and cloud deployment.

## What I work with

Python, PyTorch, data analysis, model evaluation, APIs, and deployment. I also build web tools and explore efficient machine learning on constrained devices.
